# Taskya AI Roadmap

V1.1: branding migration, Groq tool calling, Tavily search, memory, files, artifacts, voice-input UI and language selector.
V1.5: Playwright browser worker, Docker code sandbox, PDF/OCR, uploads, SSE events, cancellation and retries.
V2: computer worker, scoped folders, terminal, takeover and audit.
V3: Hindi/Hinglish voice first, then regional-language evaluation and BHASHINI integrations where useful.
V4: PostgreSQL, Redis, auth, subscriptions and usage metering.
V5: model router, caching, parallel workers, observability and a 100+ task benchmark.

Benchmark before making any claim that Taskya AI is better than another agent.
